A full end-to-end ETL pipeline with a Streamlit dashboard.

## Step-by-Step Setup

### Step 1 — Create and activate a virtual environment

```bash
python -m venv venv

# Windows
venv\Scripts\activate

# Mac / Linux
source venv/bin/activate
```

---

### Step 2 — Install dependencies

```bash
pip install -r requirements.txt
```

---

### Step 3 — Create the `data/` folder and generate raw data

Make sure the `data/` folder exists at the project root, then run:

```bash
python data/generate_data.py
```

This creates `data/raw_sales.csv` with 500 rows of fake sales data.
Some rows intentionally have issues (negative quantities, missing reps, duplicate IDs)
so the Transform step has real work to do.

---

### Step 4 — Create the `database/` folder

```bash
mkdir database
```

The pipeline will auto-create `sales.db` inside it.

---

### Step 5 — Run the ETL pipeline

```bash
python run_pipeline.py
```

What happens:
1. **Extract** → reads `data/raw_sales.csv`
2. **Transform** → removes duplicates, drops nulls, fixes negatives, adds `revenue` and `month` columns
3. **Load** → writes the clean data to `database/sales.db` (table: `sales`)

---

### Step 6 — Launch the dashboard

```bash
streamlit run dashboard/app.py
```

Open `http://localhost:8501` in your browser.

## How the ETL Works

### extract.py
Reads the raw CSV from disk using `pd.read_csv()`. No transformation here — just load and validate file existence.

### transform.py
Applies these cleaning rules in order:
- `drop_duplicates(subset=["order_id"])` — one record per order
- `dropna(subset=["sales_rep"])` — skip unassigned orders
- Filter `quantity > 0` — remove bad entries
- Compute `revenue = quantity * price`
- Parse `order_date` to datetime
- Extract `month` as a string period (e.g. `"2025-03"`)

### load.py
Uses SQLAlchemy to write the clean DataFrame to SQLite with `if_exists="replace"` — a full refresh on every run.

### analytics.py
Contains reusable query functions (`total_revenue`, `top_products`, `region_sales`) that wrap SQL queries. These are imported by `app.py`.
